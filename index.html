How it works

  1. Client sends an API request.
  2. Gateway checks the request counter.
  3. Requests within the limit are accepted.
  4. Excess requests receive HTTP 429 (Too Many Requests).

Cloud architecture

Client→API Gateway→Serverless Function→Shared Counter Store

This website is a front-end simulator. A production distributed system would enforce limits on the server and use shared storage such as Redis or a managed database.
